# Botok – AI Social Media Bots Behavior & Adaptation Study

**Bachelor's thesis project (2024)**  
Investigation of the behavior and adaptation of artificial intelligence bots on social media platforms.

This repository contains the Python application developed for the thesis, which was used to create and run multiple AI-powered bots on social media platforms in order to study their behavior, interaction patterns, and adaptation.

## Project Overview

The main goal of the research was to better understand how social media platforms influence user behavior by deploying AI bots with different personalities and observing how they interact with the platform and other users.

The application provides a simple graphical user interface so that users can easily configure and run the bots that were used during the research.

## Key Technologies

- **Python**
- **PyQt5** – Graphical user interface
- **Selenium** – Browser automation
- **PyAutoGUI** – GUI automation
- **OpenCV (cv2)** – Image processing
- **BeautifulSoup (bs4)** – Web scraping
- **NumPy & Pillow** – Data and image handling
- **Requests** – HTTP requests

## Features

- Configurable AI bots with different personalities
- Automated interaction with social media platforms (likes, comments, etc.)
- User-friendly interface for starting and controlling bots
- Tools for analyzing bot behavior and adaptation
